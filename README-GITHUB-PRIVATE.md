# مشروع المتابعة التنفيذية - نسخة خاصة

هذه نسخة كاملة من مشروع EMIZ تشمل بيانات الشركة والتقارير وعروض التأمين والمرفقات. يجب رفعها إلى مستودع GitHub خاص Private فقط، وقصر صلاحيات الوصول على المخولين. لا تنشر هذه النسخة على GitHub Pages.

## الرفع
فك الضغط ثم ارفع محتويات مجلد ceo-project من داخل الملف. يفضل Git أو GitHub Desktop للمرفقات الكثيرة. لا ترفع ملف ZIP نفسه باعتباره كود المشروع.

```sh
git init
git add .
git commit -m "Backup full CEO dashboard project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_PRIVATE_REPOSITORY.git
git push -u origin main
```

## التشغيل
افتح dashboard.html مباشرة لعرض النسخة المحفوظة بالمرفقات المحلية. المصدر القابل للتعديل داخل site/ وكود الاستيراد داخل local/ والمشروعات داخل task-projects/.

اتصالات سلة وسلاك وGoogle تعتمد على جلسة Codex المصرح بها على الجهاز ولا تنتقل بمجرد نسخ الكود. سكربتات collect*.js هي تنسيق أدوات داخل Codex وليست أوامر Node مستقلة. التشغيل التلقائي يتطلب تهيئة المسارات والمصادر على الجهاز الجديد؛ بعض السكربتات تشير إلى D:/EMIZ ومسار Python الخاص بالجهاز الحالي. لا تنفذ عمليات المزامنة قبل ضبط ذلك.

تحتوي البيانات على أوقات آخر جلب الأصلية؛ إنشاء الحزمة لا يعني جلب بيانات جديدة. التقرير الطبي يتضمن نسختي المقارنة التفصيلية والملخص.

تم استبعاد ملفات السجل والكاش والاختصار المحلي فقط. يرفق PACKAGE-MANIFEST.json بمقاس وبصمة SHA-256 لكل ملف أصلي مشمول. لم تُرفع الملفات إلى GitHub من هذه المحادثة.
